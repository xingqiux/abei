# 概况 / 交易 · 重做

原型：`阿贝 今天与交易 重做.html`（`index.html` 是它的软链，URL 里不用带中文）。
在 `designs/` 的 HTTP 服务下打开：

```
http://localhost:4311/today-transactions-redesign/index.html
```

底部有切换器：页面（概况 / 交易）、本期数据（真实 / 假设有数）、主题（亮 / 暗）。
切换器是原型自己的控件，搬回生产时不要。

方向已经定了：**概况＝时间线，交易＝紧凑表格 + 右侧面板**。
早前用来比选的另外几版（今天页的「待办优先」「一屏体检」、交易页的「收起筛选」）已经从原型里删掉，
下面只留结论和当时的取舍。

## 数据是真的

`data.jsx` 由 `gen-data.mjs` 从本机 Firefly 生成，取 2026-07 的 80 笔真实流水、
真实账户余额、真实收件箱计数。没有一个数字是编的。重跑：

```
node gen-data.mjs <存放 rows.json/accs.json 的目录>
```

图标同理，`gen-icons.mjs` 从 Iconify 拉 Phosphor（MIT），跟生产版 `@phosphor-icons/react` 同源。

## 做之前先看清楚的事

拉完真实数据才发现，这台账本的状态跟界面正在讲的故事完全不是一回事：

- **账本停在 07-15**，到今天 25 天没有任何入账。8 月的「本期支出 ¥0.00」不是没花钱，是没入账。
- **收件箱压着 178 笔**要人动手（137 待入账 + 41 待确认），最早那封欠了 86 天。
- **一条分类都没有**。`insight/expense/category` 返回空数组，80 笔全部未分类。
  也就是说生产版「今天」页那张「支出分类占比」卡在真实数据下永远不显示，
  而交易页每一行都会挂一个一模一样的「未分类」——同一句话印 80 遍。
- 净资产 −¥48,919.10，负债是资产的 6 倍多。

两页都是从这些事实出发的，不是从「仪表盘该有哪些卡片」出发的。

## 概况页（原「今天」）

改名叫**概况**：这一页说的是账本当前是什么状态，不是「今天发生了什么」——
真实情况恰恰是今天什么都没发生，叫「今天」名不副实。侧栏图标同步换成 `SquaresFour`。

原来的问题（你点的四条）都指向同一件事：**这一页在用装饰和空数字占位，
而真正该说的话没说**。问候语 + 山峰插画占掉近三分之一首屏却不产出信息；
三张 ¥0.00 大卡把「还没记账」演成「这个月没花钱」；卡片一张张平铺没有主次；
右栏两块内容各只有一两行，靠一根空柱子撑版面。

### 时间线

横幅和三张大卡都撤掉。整页按时间轴讲一遍：

- 往上是**将要发生的**：iCloud 200GB（08-11）、房租（08-15），周期扣款。
- 中间是**今天**：还没有入账，直接给「去入账」。
- 再往下是**断层**：一块带斜纹的告警区，写着「25 天没有任何入账」。这是这一页的主角。
- 最后是**账本最后一笔**（07-15 独立站项目尾款）和断层之前还活着的几天。

左列 236px 只留三个必须常驻的数字：净资产（带资产/负债量条）、本期、待处理四项 + 一个
「处理收件箱」的主动作。它不参与叙事，只负责「随时能看到」。

**取舍**：这一版最不像传统仪表盘。等日常状态好起来（每天都入账），
那块断层会消失，这一版的张力也就没了——到时候中间那段应该退成「本周入了 N 笔」之类的常态摘要。

## 交易页

### 紧凑表格 + 右侧面板

原来的 B（表格）和 C（面板）合成一版，因为它们解决的是同一个工作流的两半：
**表格负责扫读和批量，面板负责单笔细节和连续修改**。

- **筛选栏**：六个常驻控件收进一个「筛选」按钮，已选条件留成可点掉的 chip，关键词框常驻。
- **概览**：顶部一条本期概览（笔数 / 支出 / 收入 / 净流）。原版只有右上角「共 122 笔」。
- **表格**：单行、列对齐、列头常驻，日期组头也钉在列头下面。
  分组依据能从按日切到按分类 / 按账户（原版写死按日）；按日分组时日期列自动收掉，因为组头已经写了。
- **面板**：选一笔是详情 + 分类/标签快捷编辑，底下是「保存并看下一笔」；
  选多笔就变批量面板（改分类 / 改预算 / 加标签 / 删除），比底部条能装更多字段。
- **键盘**：列表里 `↑↓` 走位、`空格` 勾选、`Esc` 清空。归那 69 笔分类可以一直按下去，手不用离键盘。
- **分页**：底部翻页换成滚动加载，到底了明说「共 N 笔」。

两边宽度是协商好的，不是硬塞：**面板开着时账户列让位**（账户在面板里写得更全），
描述列因此还有 400px 上下；**面板收起**时账户列补回来、表格占满 1180，批量动作改从底部条升起。
这样「一次看几百笔」和「一笔笔改」不用二选一。

### 未分类只说一次

**「未分类」不再逐行重复**。它从每行一个虚线 chip，变成列表上方一条带动作的提示
（「这 80 笔全都还没分类 · 让 AI 归一遍 / 只看未分类」）。
表格保留分类列（列对齐需要占位），空值只写一个 `—`。

## 外壳上顺手修的一个结构问题

`.app` 只锁了 `height: 100vh`，没锁网格行高，行会被内容撑开——结果 `.canvas` 那个
`overflow: auto` 永远不滚动，页面是整体滚的。副作用是顶栏和侧栏跟着一起走，
所有 sticky（列头、日期组头、批量条）全部失效。
现在 `.app` 加了 `grid-template-rows: minmax(0, 1fr)` 和 `overflow: hidden`，
`.main` 加了 `min-height: 0`，`.side` 自己滚。搬回生产时这一条要一起带上。

## 视觉沿用

token 全部搬自 `abei-web/src/index.css`：墨蓝 `--brand`、中性冷灰分层、
收入红 `--income`、支出用正文色、转账蓝 `--transfer`、需要注意用琥珀 `--attention`。
暗色是同一套 token 的第二组值，切换器里可以直接看。
数字一律 `font-variant-numeric: tabular-nums`，金额列才对得齐。
