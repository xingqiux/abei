# 账单收件箱 · 重做说明

原型：`账单收件箱 重做.html`（本地起服务后打开，`python3 -m http.server 4311 --directory designs`）。
左下角「Tweaks」里切换四组变体：行结构、加载方式、来源面板、密度／主题，另附平台标记一览。

**定稿的一组（打开就是这个）：A 单行 + 滚动加载 + 顶部渠道条（固定）+ 紧凑。**
其余版本留在 Tweaks 里，方便回头比对。

设计语汇沿用 `abei-web/src/index.css` 的 token（墨蓝品牌、中性冷灰分层、44px 行高、
金额等宽 tabular-nums），新增的只有一组平台色 `--pf-*`：直接取各平台自己的品牌色，
浅色主题用原色、深色主题用调亮过的一支（`--pf-dark`），只做来源区分，不承载语义。

## 五个问题各自落在哪

**1 · 收件箱要能收起**
来源面板三态：展开 252px ／ 收起成 44px 的平台图标条（带未处理数徽标，点一下就回来）／
换成顶部渠道条（面板整个收进一排 chip，主区拿到全宽）。定稿走第三态，前两态留着。

**2 · 不同平台要有不同的 svg**
用各家真实的品牌标，不是手画的抽象形。路径从 Iconify 的公开图标集抓下来落进
`brand.jsx`，页面不联网、不发外部请求：

| 平台 | 取自 | 平台 | 取自 |
| --- | --- | --- | --- |
| 支付宝 | `simple-icons:alipay` | 云闪付 | `logos:unionpay` |
| 微信支付 | `simple-icons:wechat` | 花呗 | `ri:alipay-fill`（蚂蚁一家，换橙色区分） |
| 财付通 | `ri:wechat-pay-fill` | 拼多多 | `arcticons:pinduoduo` |
| 招商银行 | `arcticons:china-merchants-bank` | 京东 | `arcticons:jd-com` |
| 中国银行 | `arcticons:boc`（古钱） | 美团 | `simple-icons:meituan` |
| 抖音支付 | `simple-icons:tiktok`（同一个标） | Apple / iCloud | `simple-icons:icloud` |

认不出来源时兜底一个信封，不冒充任何一家。图标文件本身来自 CC0 / Apache-2.0 / CC BY-SA
的图标集，可自由使用；**商标仍归各平台所有**，这里只作「这笔流水来自谁」的识别。

两处需要你拍板：
- **云闪付**只有横向字标（`logos:unionpay`），塞进 20px 方块里会糊，现在让它占满底块宽度，
  仍然不如别家清楚。要更清楚就得拿官方品牌包里的方形版。
- **招行 / 中行 / 拼多多 / 京东**在 CC0 图标集里没有，用的是 arcticons 的描边版，
  笔画比别家细一档。同样，官方品牌包能换掉。

**3 · 渠道和流水要分层**
面板里渠道头给平台色底块、加粗，是「站台」；邮件行退到引导线右边、字号降一档、
状态用小色点，是挂在站台下的「车厢」。主区每行左端也带平台标 —— 原来那句
「支付宝-上海盒马网络科技有限公司」里的平台前缀被拆出来当图标，描述只留商户名。

**4 · 待入账列表信息量太少**
- 日期从每行搬到粘性分组头，头上带当日笔数与合计（原来 9 行重复印 9 遍 08-08）。
- 账户列只留资金账户，不再印「招行信用卡(5599) → …」这种两端都截断的流向。
- 描述拆成「平台标 + 商户名」，分类 chip 常驻，AI 建议走虚线框。
- 页头加一条工作量：待处理笔数、支出、收入、最早一笔积压多久、本次处理进度。
  原来只有一个「114 笔」，看不出该不该现在动手。
- 行内动作浮在行右端，盖住的是账户列而不是金额 —— 金额要一直看得见。

**5 · 平铺没有分页**
三种切法：滚动加载（定稿；每次续 20 笔，到底明确写「到底了 · 共 N 笔」，不留悬念）／
分页器（20/50/100 每页，页码 + 区间计数）／按邮件批次折叠（一封邮件一段，段头写
「解析出 9 笔 · 合计 -¥306.79」，可整批全选、整批入账）。

配合滚动加载，**状态 tab + 渠道条钉在视口顶端**：滚到第 300 行也能直接切来源、切状态、
看清当前筛的是谁。日期分组头和表头贴着这条的下沿吸附（高度量出来写进 `--stick-h`，
选中渠道多出一行邮件 chip 时会自己跟上）。这里有个坑记一笔：列表卡片原来用
`overflow: hidden` 切圆角，它会变成最近的滚动容器，里面的分组头就只贴卡片上沿、
跟顶部条对不齐 —— 改成让首尾子元素自己带圆角。

## 三版行结构

- **A 单行**（默认）：日期靠分组头，一行只放商户、分类、账户、金额。一屏能看十几笔。
- **B 双行**：主行给完整商户名和金额，次行放分类 · 平台 · 账户。来源邮件不放次行 ——
  同一封邮件的几十笔会把它重复几十遍，那正是原来最吵的地方，要看来源展开行里有。
- **C 表格**：日期回到列里，真表头 + 列对齐，不分组。适合一次扫几百笔。

## 待确认 tab

按「要你做什么判断」分节：疑似转账／疑似重复／需拆分／需补备注，每节一句话说清在判断什么，
行内直接给那一类的动作（确认转账、不是重复、拆分、补备注）。

## 品牌标怎么重新生成

`gen-brand.mjs` 里那张 SPEC 表写着「哪个平台用哪个图标、配什么色」，改完跑：

```sh
node designs/bill-inbox-redesign/gen-brand.mjs designs/bill-inbox-redesign/brand.jsx
```

会重新拉 Iconify 的 JSON 接口，把 viewBox 和 path 落进 `brand.jsx`。要换成官方品牌包里的
svg，就把那一条的 `vb` / `body` 手填进去，其余不用动。
