# 谷仓 Granary · UI 与前端交互规范 v2.0

> 2026-07-09 定稿。本版按选型结论重写，选型记录：
> **Q1 配色=藏青×琥珀金 · Q2 字体=MiSans · Q3 定位=高信息密度 · Q4 卡片=柔和阴影 ·
> Q5 表格=紧凑32px · Q6 导航=经典侧栏 · Q7 动效=L3丰富(GSAP+Lottie) · Q8 架构=全面切新前端 · Q9 英文名=Granary**
> 可视化版见 Artifact「谷仓 Granary · UI 设计规范」；工程方案见 `granary-web-plan.md`。
> v1.0 草案中与本版冲突的内容一律以本版为准。

## 0. 定位与原则

谷仓是 **AI 与人共同操作的记账系统**：记录主要由 firefly-cli / AI / 账单收件箱完成，
Web 端（granary-web）是人用来**审阅、对账、分析**的高密度工作台。

1. **高信息密度优先**：单屏尽量多信息，紧凑行高、多栏并置，专业工具感（彭博终端/IDE 方向）；
   美观通过秩序（对齐、等宽数字、一致的间距节奏）实现，而不是通过留白。
2. **颜色即语义**：1 个品牌强调色（琥珀金）+ 3 个记账语义色（收/支/转）+ 2 个状态色（警/危），其余中性。
3. **首屏必须有内容**：默认日期范围=最近 30 天，空则回退到最近有数据的月份；空状态必须给动作。
4. **审阅流优先**：待审账单、未对账天数常驻总览与侧栏徽标。
5. **动效只为状态变化服务**：入账、同步、切页、数字更新才动；纯装饰循环只允许出现在空状态/等待场景。

## 1. 品牌

- 名称：**谷仓 / Granary**。字标：MiSans Demibold「谷仓」+ JetBrains Mono 加字距「GRANARY」。
- 默认主题：**深色**（藏青底最能体现 AI 控制台气质）；浅色为完整支持的次主题，跟随系统+手动切换。

## 2. 设计 Token

### 2.1 色彩（dark 为默认）

| Token | Dark（默认） | Light | 用途 |
|---|---|---|---|
| `--g-bg` | `#0A0F1C` | `#ECECEA` | 页面底 |
| `--g-surface` | `#111A2E` | `#FFFFFF` | 卡片/表格底 |
| `--g-surface-2` | `#1A2745` | `#F4F4F2` | 表头、hover、分组行、chip 底 |
| `--g-border` | `#243356` | `#DCDCD8` | 表格内分隔线（卡片本身无边框） |
| `--g-ink` | `#E8EBF2` | `#14192B` | 主文字 |
| `--g-ink-2` | `#8A94AB` | `#6A7183` | 次要文字 |
| `--g-accent` | `#FCA311` | `#D97E00` | 品牌琥珀金：主按钮、当前导航、焦点、强调数据点 |
| `--g-accent-ink` | `#14213D` | `#FFFFFF` | 琥珀底上的文字 |
| `--g-income` | `#45C08F` | `#17805F` | 收入金额 |
| `--g-expense` | `#F07E64` | `#C05237` | 支出金额（珊瑚，非红色——支出不是错误） |
| `--g-transfer` | `#7E9BC9` | `#4E6E8E` | 转账金额 |
| `--g-warn` | `#E8C15A` | `#9A7A16` | 待处理、临近超支（与琥珀强调色区分：更黄、只用于状态） |
| `--g-danger` | `#E5484D` | `#C4302B` | 失败、删除、余额差异 |
| `--g-shadow` | `0 1px 2px rgb(0 0 0/.35), 0 8px 24px rgb(0 0 0/.35)` | `0 1px 2px rgb(16 20 40/.06), 0 8px 24px rgb(16 20 40/.10)` | 卡片双层柔影 |

- 语义色只上金额文字、状态点、徽标和细条；整块高饱和色面只允许琥珀金主按钮。
- 浅色主题正文级琥珀文字用 `#B26400`（对比度达标），`#D97E00` 只用于按钮底和大号元素。
- 图表分类色板（6+1，dark）：`#FCA311 #45C08F #7E9BC9 #D98BA6 #A3B36B #C9873B` + 其他 `#5C6880`；
  超过 6 类聚合为"其他"。light 版整体降一档明度。

### 2.2 字体

```css
--g-font-ui:  "MiSans", -apple-system, "PingFang SC", "HarmonyOS Sans SC", sans-serif;
--g-font-num: "JetBrains Mono", ui-monospace, "SF Mono", Menlo, monospace;
```

- MiSans 自托管 woff2 子集（GB2312 一级字 + 常用符号），权重 400 / 500 / 600 三档；
  JetBrains Mono 400 / 600。构建期用 fonttools 子集化，进 Vite asset pipeline。
- 所有金额/余额/账号/日期数字：mono + `font-variant-numeric: tabular-nums` + 右对齐 + 千分位。
- 字阶（高密度）：页面标题 18/600 · 卡片标题 12/500 大写字距（辅助色）· 正文 13/400 ·
  表格 12.5/400 · 辅助 11.5 · KPI 数字 20/600 mono · 全局行高 1.5。

### 2.3 密度 / 圆角 / 层级

- 4px 网格；页面边距 20，卡片内边距 12–14，卡片间距 12，区块间距 20。
- **表格行高 32px**，表头 28px；单元格左右 padding 8。一屏（900px 高）约 24 行交易。
- 圆角：卡片 10、控件 6、chip 4。
- 层级：卡片=柔和双层阴影、无边框；表格内部用 `--g-border` 髮丝线；浮层（下拉/弹窗/命令面板）
  在阴影外加 1px `--g-border` 描边防止深色底上糊掉。

### 2.4 背景与质感

深色底不是纯平的，由三层构成（全部低调，表格区域必须干净）：
底色 `--g-bg` → 谷物噪点层（grain SVG 平铺，透明度 3–5%，谷仓唯一允许的主题隐喻）→
琥珀光晕（每页最多一处 radial，`#FCA311` 6–8%，浅色主题 `#D97E00` 4–5%）。
资产获取见 `asset-collection-guide.md` §2。

### 2.5 动效 Token

```css
--t-fast: 120ms;  /* hover、焦点、chip */
--t-base: 240ms;  /* 路由过渡、卡片入场、展开收起 */
--t-slow: 480ms;  /* 图表生长、hero 数字 */
--ease-out: cubic-bezier(.22, 1, .36, 1);   /* granary-out，默认 */
--ease-spring: cubic-bezier(.34, 1.56, .64, 1); /* 仅 Lottie 类弹性反馈 */
```

## 3. 信息架构

侧边栏（经典侧栏，200px，常驻展开；<1080px 折叠为 56px 图标栏，<768px 移动端底部 5 tab）：

```
总览
交易                  （全部/支出/收入/转账 = 页内 tab）
账单收件箱  [warn 徽标: 需验证码+待处理+失败]
按天对账    [danger 徽标: 未对账天数]
预算与订阅  （预算/订阅/储蓄罐 三 tab）
账户        （资产/支出/收入/负债 页内 tab）
报表
设置        （分类·标签·团体/规则/定期交易/币种/账套/偏好/令牌）
```

顶栏 44px 固定三件事：全局搜索（`/` 聚焦，Cmd+K 命令面板同入口）、日期范围（默认最近 30 天）、
`+ 记一笔`（琥珀主按钮，全局唯一）。

## 4. 关键页面（要点）

- **总览**：KPI 行（本期支出/收入/净现金流/总净资产，20px mono 数字 + 对比上期）→ 待办卡
  （收件箱待审 N 条 / 未对账 N 天，琥珀左条）→ 双栏：分类支出横向条形（Top 8+其他）+ 近期交易 12 行
  → 账户余额面积线（最多 4 条）。
- **交易列表**：32px 行、按日分组、组头右侧当日小计；行=描述+分类chip | 账户流向(次要色 a→b) |
  金额(mono 语义色)；行尾操作 hover 显示；无限滚动加载；`j/k/e` 键盘导航。
- **记一笔**：金额优先（大号、自动聚焦）+ 描述/来源/目标/日期共 5 字段首屏；
  类型=分段控件；其余折叠进"更多选项"。
- **账单收件箱**：计数徽标 0=灰、待办=warn、失败=danger；同步中 Lottie 状态；新入库行有入场动效。
- **按天对账**：30 天日历带（绿=已对/黄=差异/灰=无交易/红=未对），差额行置顶 + "生成调整交易"。
- **报表**：打开直接渲染本月默认报表；配置收进右侧抽屉。

## 5. 组件（要点）

- 按钮四种：主（琥珀底）/次（surface-2 底）/危险（红字，确认框内红底）/链接式。高度 28（表格内）/32（表单）。
- chip 只用于分类与状态，18px 高、4px 圆角；账户不用 chip。
- 空状态：Lottie 插画（本地托管）+ 一句话 + 主操作。加载：骨架屏。反馈：右上 toast。
- 破坏性操作确认框必须写对象名与数量。
- 命令面板（Cmd+K）：搜索、跳页、快捷记账三合一——高密度工具的核心入口之一。

## 6. 动效规范（L3 · GSAP + Lottie）

原则：**只在状态变化时动**；所有动效尊重 `prefers-reduced-motion`（降级为瞬时切换）；
单页同时最多一个"大动效"。

| 场景 | 触发 | 实现 | 时长 |
|---|---|---|---|
| 路由转场 | 切页 | GSAP：旧页 fade-out 8px ↑，新页 fade-in 12px ↑ | 240ms |
| 总览 hero 数字舞台 | 进入总览/切日期范围 | GSAP 数字滚动（expo-out），四个 KPI 依次 60ms stagger | 800ms |
| 列表入场 | 首次加载 | 行 stagger 24ms/行，上限 12 行，其余直接显示 | 240ms/行 |
| 图表生长 | 图表进入视口 | D3 算坐标 + GSAP 驱动 SVG；条形从 0 生长 | 480ms |
| 列表重排/筛选 | 筛选、排序 | GSAP Flip | 240ms |
| 入账成功 | 保存交易 | Lottie 打勾（一次性）+ toast | ~600ms |
| 收件箱同步 | 手动/自动同步 | Lottie 循环（仅等待期间）+ 新行入场 | 同步时长 |
| 空状态 | 无数据 | Lottie 低频呼吸循环（唯一允许的常驻循环） | — |
| 对账差额出现 | 差额 ≠ 0 | 差额行红色细条 240ms 展开 + 数字滚动 | 240ms |
| hover/焦点 | 全局 | CSS transition | 120ms |

- Lottie 素材（6 个场景）按 `asset-collection-guide.md` 搜集，**下载 JSON 本地托管**，
  dotlottie-web 播放，禁止运行时外链；动效图标只用于状态反馈与空状态，同屏最多一个在播。
- GSAP 用 core + Flip（免费版足够）；统一封装 `useCountUp` / `usePageTransition` / `useStaggerIn` hooks。
- **lenis 平滑滚动**：只挂阅读型长页（报表、设置）；交易列表/收件箱/对账等操作型页面禁用
  （与虚拟滚动和 `j/k` 键盘走行冲突）。
- **matter.js 物理**：仅两个场景——空状态"谷粒落仓"彩蛋、里程碑庆祝（对账清零/储蓄达成）；
  独立 chunk 懒加载，reduced-motion 时整个模块不加载。
- **图表动画**：D3 只算坐标，React 渲染 SVG，动画统一由 GSAP 驱动，保证与全站 token 一致。

## 7. 落地

架构结论（Q8）：**全面切换到新前端 `granary-web/`**，v1 不再投入任何美化，仅保持可用作过渡兜底。
阶段划分、技术选型、API 缺口清单见 `docs/design/granary-web-plan.md`。
